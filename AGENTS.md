# Bitavu Node.js SDK

Use the public Bitavu v1 API contract. The Studio implementation is maintained separately. Keep the TypeScript client free of runtime dependencies and keep template data generic.

Use the approved GitHub noreply identity for commits. Keep credentials, private contact details, customer data, and private source out of commits, CI logs, and packages. Use fictional data in examples and tests.

Run `npm ci`, `npm test`, and `npm run check:package` to verify the SDK. Build the Next.js example when changing its integration or the relevant public API.

Keep the repository private until the owner approves public visibility. Obtain explicit owner approval of the exact reviewed package before publishing. Audit source, history, package, metadata, CI logs, and artifacts before release. See [RELEASING.md](./RELEASING.md).
